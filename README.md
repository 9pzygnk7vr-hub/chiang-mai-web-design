* **ชื่อผู้จัดทำ:** นายดลโชค จิตต์มั่น
* **รหัสนักศึกษา:** 69143850
* **สาขาวิชา:** เทคโนโลยีคอมพิวเตอร์และดิจิทัล มหาวิทยาลัยราชภัฏเชียงใหม่
* **รายวิชา:** Introduction to Web Design

---

## 1. การวิเคราะห์วัตถุประสงค์และกลุ่มเป้าหมาย (Objective & Target Audience)

### **วัตถุประสงค์ของเว็บไซต์ (Objectives)**
1. เพื่อแนะนำสถานที่ท่องเที่ยวที่น่าสนใจ คาเฟ่ และวัฒนธรรมในจังหวัดเชียงใหม่ให้กับนักท่องเที่ยวทั้งชาวไทยและชาวต่างชาติ
2. เพื่ออำนวยความสะดวกในการวางแผนการเดินทาง ค้นหาข้อมูลสถานที่ และพิกัดการเดินทางได้อย่างรวดเร็ว
3. เพื่อฝึกฝนและประยุกต์ใช้หลักการออกแบบเว็บ (Web Design Principles) การจัดวางเลย์เอาต์ และการใช้งาน UI/UX ที่ตอบโจทย์ผู้ใช้งาน

### **กลุ่มเป้าหมาย (Target Audience)**
* **กลุ่มหลัก:** นักท่องเที่ยวรุ่นใหม่ นักศึกษา และวัยทำงาน (อายุ 18–35 ปี) ที่ชื่นชอบการเดินทางท่องเที่ยว คาเฟ่ชิคๆ และธรรมชาติ
* **กลุ่มรอง:** นักท่องเที่ยวทั่วไปและชาวต่างชาติที่ต้องการข้อมูลการเดินทาง วัฒนธรรม และสถานที่ท่องเที่ยวไฮไลต์ในเชียงใหม่

## 2. การออกแบบผังเว็บไซต์ (Sitemap - อย่างน้อย 4 หน้า)

โครงสร้างเว็บไซต์ถูกออกแบบให้ใช้งานง่าย ไม่ซับซ้อน (User-Friendly Navigation):

```text
[ หน้าแรก (Home) ]
 ├── [ หน้าสถานที่ท่องเที่ยว (Attractions) ] ──> [ หน้ารายละเอียดสถานที่ (Detail Page) ]
 ├── [ หน้าคาเฟ่และร้านอาหาร (Cafes & Food) ]
